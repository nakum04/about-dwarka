# પવિત્ર શ્રી દ્વારકા યાત્રા અને પ્રવાસન પોર્ટલ (Dwarka Pilgrimage & Tourism Portal)

આ એક સંપૂર્ણ ડાયનેમિક (Dynamic), આકર્ષક અને રિસ્પોન્સિવ વેબસાઇટ છે જે **PHP**, **MySQL (phpMyAdmin)**, **HTML5**, **CSS3**, અને **JavaScript** નો ઉપયોગ કરીને બનાવવામાં આવી છે.

---

## 🌟 મુખ્ય વિશેષતાઓ (Features Included):

1. **દ્વારકા શું છે? (What is Dwarka?):**
   - હિન્દુ ધર્મના ૪ પવિત્ર ધામ પૈકીનું પશ્ચિમ ધામ.
   - સપ્ત મોક્ષદાયી પુરી (અયોધ્યા, મથુરા, માયા, કાશી, કાંચી, અવંતિકા અને દ્વારાવતી) નું પૌરાણિક મહત્વ.
   - ગોમતી નદી અને અરબી સમુદ્રનો પવિત્ર સંગમ તથા મોક્ષ મેળવવાની માન્યતા.

2. **દ્વારકામાં કયા ભગવાનનું મંદિર છે? (Which Deity's Temple?):**
   - **શ્રી દ્વારકાધીશ જગત મંદિર** — ભગવાન શ્રીકૃષ્ણ (રાજાધિરાજ - ચતુર્ભુજ શ્યામ સ્વરૂપ શંખ, ચક્ર, ગદા અને પદ્મ સાથે).
   - ૫૨ ગજની ધજાનું આધ્યાત્મિક મહત્વ (દિવસમાં ૬ વખત ધ્વજારોહણ).
   - સ્વર્ગ દ્વાર (પ્રવેશ - ૫૬ પગથિયાં) અને મોક્ષ દ્વાર (નિકાસ).
   - ૭૨ કલાત્મક સ્તંભો અને ૫ માળનું પૌરાણિક સ્થાપત્ય.
   - **દૈનિક દર્શન અને આરતી સમયપત્રક:** મંગળા આરતી (૬:૩૦ AM), શૃંગાર દર્શન, રાજભોગ, ઉત્થાપન, સંધ્યા આરતી (૭:૩૦ PM), શયન ભોગ.

3. **દ્વારકામાં જોવાલાયક સ્થળો (Places in Dwarka City):**
   - શ્રી દ્વારકાધીશ જગત મંદિર
   - પવિત્ર ગોમતી ઘાટ અને સંગમ
   - સુદામા સેતુ (કેબલ સસ્પેન્શન બ્રિજ)
   - ભડકેશ્વર મહાદેવ મંદિર (દરિયા વચ્ચે શિવ મંદિર & સનસેટ વ્યૂ)
   - દ્વારકા બીચ અને ૪૩ મીટર ઊંચી દીવાદાંડી (Lighthouse)
   - ગીતા મંદિર અને આદિ શંકરાચાર્ય સ્થાપિત શારદા પીઠ
   - પંચનદ તીર્થ (પાંડવોના ૫ મીઠા પાણીના કૂવા)

4. **દ્વારકાની આજુબાજુ જોવાલાયક સ્થળો (Nearby Attractions):**
   - **બેટ દ્વારકા (શંખોદ્ધાર બેટ):** શ્રીકૃષ્ણ-સુદામા મિલન ભૂમિ અને નવનિર્મિત ભવ્ય **સુદર્શન સેતુ** (ભારતનો સૌથી લાંબો કેબલ બ્રિજ).
   - **શ્રી નાગેશ્વર જ્યોતિર્લિંગ:** ૧૨ પવિત્ર જ્યોતિર્લિંગ પૈકીનું દારૂકાવન જ્યોતિર્લિંગ અને ભગવાન શિવની ૮૨ ફૂટ ઊંચી વિશાળ પ્રતિમા.
   - **શિવરાજપુર બ્લુ ફ્લેગ બીચ:** આંતરરાષ્ટ્રીય બ્લુ ફ્લેગ પ્રમાણિત સ્વચ્છ સફેદ રેતીનો દરિયાકિનારો, સ્વિમિંગ, વોટર સ્પોર્ટ્સ અને સ્કૂબા ડાઇવિંગ.
   - **શ્રી રુક્ષ્મણી દેવી મંદિર:** ૧૨મી સદીનું પૌરાણિક મંદિર (દુર્વાસા ઋષિના શ્રાપ અને જળદાનની કથા).
   - **ગોપી તળાવ:** શ્રીકૃષ્ણ-ગોપી રાસ સ્થળ અને પવિત્ર પીળી માટી (ગોપી ચંદન).

5. **દ્વારકા ફરવા માટેનું સમયપત્રક (Tour Timetable / Itineraries):**
   - **૧ દિવસીય એક્સપ્રેસ પ્લાન:** મંગળા આરતી, ગોમતી સ્નાન, નાગેશ્વર, બેટ દ્વારકા અને સંધ્યા દર્શન.
   - **૨ દિવસીય શ્રેષ્ઠ પ્રવાસ (ભલામણ કરેલ):** પ્રથમ દિવસે દ્વારકા નગરી દર્શન અને બીજા દિવસે આસપાસના તમામ તીર્થો.
   - **૩ દિવસીય આરામદાયક ટૂર:** દર્શન ઉપરાંત શિવરાજપુર બીચ, સ્કૂબા ડાઇવિંગ અને સ્થાનિક ખરીદી.
   - પ્રવાસનું સમયપત્રક પ્રિન્ટ / પીડીએફ સેવ કરવાની સુવિધા.

6. **બજેટ અને ખર્ચ ગાઇડ (Normal Hotel & Gujarati Food Budget):**
   - **સામાન્ય હોટેલ / ધર્મશાળા:** ₹૫૦૦ - ₹૭૦૦ (ધર્મશાળા/આશ્રમ), ₹૧,૦૦૦ - ₹૧,૪૦૦ (નોર્મલ બજેટ હોટેલ AC/Non-AC).
   - **નોર્મલ ગુજરાતી / કાઠિયાવાડી ભોજન:** ₹૧૨૦ - ₹૧૫૦ પ્રતિ થાળી (અનલિમિટેડ ૨ શાક, રોટલી/ગરમાગરમ બાજરાના રોટલા, દાળ-ભાત, ગોળ, માખણ, મસાલા છાશ, પાપડ).
   - **વાહન વ્યવહાર:** શેરિંગ બસ/રિક્ષા (₹૧૫૦/દિવસ), પ્રાઇવેટ ઓટો (₹૮૦૦/દિવસ), પ્રાઇવેટ કાર (₹૨,૨૦૦/દિવસ).
   - **લાઈવ ઇન્ટરેક્ટિવ બજેટ કેલ્ક્યુલેટર:** દિવસો (૧-૭), વ્યક્તિઓની સંખ્યા અને હોટેલ-ભોજન પસંદ કરી લાઈવ ખર્ચ ગણો.

7. **દ્વારકાનો ઐતિહાસિક વારસો (History of Dwarka):**
   - ૫૦૦૦+ વર્ષ પૂર્વે વિશ્વકર્મા દ્વારા સોનાની નગરીનું નિર્માણ.
   - મહાભારત યુદ્ધ બાદ સમુદ્રમાં જળમગ્ન થવું (સુનામી/સમુદ્ર મોજાં).
   - પ્રપૌત્ર વજ્રનાભ દ્વારા પ્રથમ મંદિર નિર્માણ.
   - આદિ શંકરાચાર્ય દ્વારા શારદા પીઠની સ્થાપના.
   - સમુદ્ર તળે સંશોધન (ડૉ. એસ. આર. રાવ અને ૨૦૨૪માં વડાપ્રધાન નરેન્દ્ર મોદીજી દ્વારા સ્કૂબા ડાઇવિંગ પૂજા).

8. **ઇન્ટરેક્ટિવ સુવિધાઓ:**
   - **મંદિર ઘંટનાદ (Temple Bell Audio Chime):** Web Audio API દ્વારા વાસ્તવિક મંદિર ઘંટનાદનો અવાજ.
   - **લાઈવ ભારતીય સમય ઘડિયાળ (Live IST Clock)**.
   - **લાઈવ સર્ચ અને ફિલ્ટર:** સ્થળોને કેટેગરી મુજબ ફિલ્ટર કરો.
   - **મોડલ ડાયલોગ:** દરેક સ્થળની પૂર્ણ વિગત ક્લિક કરતાં ખૂલે છે.
   - **યાત્રી પ્રતિભાવ અને પૂછપરછ સિસ્ટમ:** MySQL ડેટાબેઝ સાથે AJAX કનેક્ટેડ.

## 🚀 વેબસાઇટ કેવી રીતે ચલાવવી? (How to Run in XAMPP):

1. **XAMPP Control Panel** ખોલો અને ખાતરી કરો કે:
   - **Apache**: `Running` (Port 80/443)
   - **MySQL**: `Running` (Port 3306)

2. બ્રાઉઝર (Chrome, Edge, Firefox) ખોલો અને આ લિંક પર જાઓ:
   ```
   http://localhost/about dwarka/
   ```
   અથવા
   ```
   http://localhost/about%20dwarka/
   ```

3. **ડેટાબેઝ (phpMyAdmin):**
   - બ્રાઉઝરમાં `http://localhost/phpmyadmin/` ખોલો.
   - ડાબી બાજુ તમને `dwarka_guide` નામનો ડેટાબેઝ જોવા મળશે.
   - તેમાં નીચેના ટેબલ ઉપલબ્ધ છે:
     - `places` (દ્વારકા અને આજુબાજુના તમામ જોવાલાયક સ્થળો)
     - `itineraries` (૧, ૨, ૩ દિવસીય સમયપત્રક)
     - `aarti_timings` (મંગળા, શૃંગાર, રાજભોગ, સંધ્યા આરતીનો સમય)
     - `budget_rates` (હોટેલ, કાઠિયાવાડી થાળી, વાહન વ્યવહારના દરો)
     - `history_timeline` (દ્વારકાનો ૫૦૦૦ વર્ષનો ઐતિહાસિક વારસો)
     - `reviews` (યાત્રીઓના પ્રતિભાવો)

### ૨. એડમિન પેનલની વિશેષતાઓ (Admin Features):
- **📊 ડેશબોર્ડ (Dashboard):** તમામ સ્થળો, આરતી, સ્લોટ્સ અને રિવ્યુની લાઈવ આંકડાકીય માહિતી.
- **🏛️ જોવાલાયક સ્થળો મેનેજમેન્ટ (Places):** નવું સ્થળ ઉમેરો, હાલના સ્થળમાં ફેરફાર કરો, નવો ફોટો અપલોડ કરો કે ડિલીટ કરો.
- **🔔 દર્શન & આરતી સમય (Aarti Timings):** કોઈપણ આરતીનો સમય કે નામ ઉમેરો, સુધારો કે હટાવો.
- **🗓️ ટૂર સમયપત્રક (Tour Itinerary):** ૧, ૨ અને ૩ દિવસીય પ્રવાસના કાર્યક્રમોમાં ફેરફાર કરો.
- **💰 બજેટ & ખર્ચ દરો (Budget Rates):** હોટેલ, ગુજરાતી થાળી અને વાહન વ્યવહારના ભાવો બદલો (જે બદલતાં જ વેબસાઇટના લાઈવ કેલ્ક્યુલેટરમાં પણ નવો ભાવ આવી જશે!).
- **📜 ઇતિહાસ ટાઇમલાઇન (History):** પૌરાણિક અને ઐતિહાસિક વારસાના પ્રસંગો ઉમેરો/બદલો.
- **💬 યાત્રી પ્રતિભાવો (Reviews):** મુલાકાતીઓના રિવ્યુ જુઓ, નવા ટેસ્ટીમોનિયલ ઉમેરો અથવા અયોગ્ય રિવ્યુ કાઢી નાખો.
- **⚙️ વેબસાઇટ લાઈવ સેટિંગ્સ (Live Settings):** ટોપ જાહેરાત પટ્ટીનું લખાણ, હીરો બેનરનું હેડિંગ, ૪ આંકડાકીય કાઉન્ટર્સ, શ્રેષ્ઠ ઋતુ અને ફૂટર શ્લોક સીધા બદલો તથા એડમિન પાસવર્ડ પણ બદલી શકો છો.
